# Structure Client (Fabric, Minecraft 1.21.11, Java 21)

Build:  gradle build   (or push to GitHub: Actions builds the JAR for you, see Actions > build > Artifacts)
Install (Zalith): install Fabric Loader for 1.21.11 + Fabric API, put build/libs/structure-client-*.jar in the mods folder.

Open menu: Right Shift.  Panic: Delete.  Right Shift again closes.
Configs: <game dir>/config/structure-client/
